2. A/B Test: Homepage hero CTA

Hypothesis: Changing CTA from “Learn More” → “Get 10% Off First Order” will increase click-through from 2.1% to 3.0% because offer > information for new visitors.

  • Primary metric: hero CTR. Guardrails: bounce rate, checkout start.
  • Sample: 50/50 split, 2 weeks, min ~2,000 sessions per variant (use a sample-size calculator — link it).
  • Result (sample): B wins 3.2% vs 2.0% (+60% rel, p < 0.05). No harm to bounce.
  • Decision: Ship B to 100%, then test offer value vs free shipping next.
Takeaway: Always pair a dashboard with a decision. Dashboards describe — tests decide.
